# Data directory

- `synthetic_crop_panel.csv`: simulated rows for tests and smoke runs. **Not real Pakistan observations.** See `SYNTHETIC_DATA_NOTICE.md`.
- `pbs_crop_panel.csv`: created on your machine by `fetch-pbs`; not committed.
- `pbs_crop_panel.provenance.json`: written by `fetch-pbs`; records the source URL, UTC retrieval time, SHA-256 of the downloaded file and row counts. Commit this file with any results.
